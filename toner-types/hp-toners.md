# Тонеры для HP

В папке ЗАПРАВКА есть файлы:
- `HP Bulat чёрные.docx/pdf` — тонер Bulat для чёрных картриджей HP
- `hp.docx/pdf` — общая информация по HP

## Распространённые тонеры
- HP Color LJ CP1025 / M176 — универсальный цветной тонер, используется в т.ч. для Canon 069
- HP 85A / 85X / 12A / 78A / 83A — популярные модели
