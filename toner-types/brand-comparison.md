# Сравнение марок тонера

## Bulat
- Популярен в России
- Есть карта применения для Samsung/Xerox
- Есть отдельная линейка для HP чёрных

## TMC-040 (TMC40)
- Используется для Canon 069
- По отзывам на testcopy.tech — спорное качество
- Возможны проблемы с калибровкой цветов

## Grafit
- Рекомендуется на testcopy.tech
- Артикул: TN-HP-252-BK-55-GR
- Хорошие отзывы для Canon 069

## Aji
- Упомянут на testcopy.tech
- Используется для CF218A и аналогичных
