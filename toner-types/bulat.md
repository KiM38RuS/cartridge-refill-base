# Bulat — тонеры для заправки

## О бренде
Bulat — популярный бренд совместимого тонера для заправки лазерных картриджей. Производится в Китае.

## Продукция
- **Bulat HP чёрные** — тонер для чёрных картриджей HP
- **Bulat цветной** — тонер для цветных картриджей HP/Canon

## Карта применения
Существует карта применения тонеров Bulat для печатающих устройств Samsung и Xerox (файл `Bulat Карта применения Тонеров для Samsung и Xerox.png`).

## Совместимость
- Подходит для заправки картриджей HP и Canon
- Для Canon 069HY рекомендуется (данные из обсуждений testcopy.tech)
