# Сброс счётчиков Kyocera

## Общие принципы

Kyocera использует **блокирующие чипы** на большинстве картриджей TK-серии. Однако у многих современных моделей ECOSYS есть возможность сброса счётчика **без замены чипа** — через комбинацию кнопок на панели принтера.

| Способ | Где работает | Сложность |
|---|---|---|
| [OK] + [Отмена] (3 сек) | Современные ECOSYS (FS-1xxx, FS-2xxx, FS-4xxx) | 🔹 Просто |
| Механический флажок | MA2001 / PA2001 / PA2000 (TK-1248) | 🔹 Просто |
| Сервисное меню (10871087) | Старые модели с цифровой клавиатурой | 🔸 Средне |
| Замена чипа | Все модели где нет кнопочного сброса | 🔹 Просто |

> **Важно:** даже если сброс кнопками возможен, принтер может снова запросить подтверждение при следующем включении. Если это надоедает — замените чип.

---

## Способ 1 — Кнопки [OK] + [Отмена] (основной)

Работает на большинстве современных **ECOSYS** (FS- и M-серии):

> **Одновременно нажать и удерживать кнопки [OK] и [Отмена/Стоп] не менее 3 секунд.**

После этого сообщение «Установлен неоригинальный картридж с тонером» или «Замените тонер» должно исчезнуть.

### Подтверждённые модели:

| Серия | Модели |
|---|---|
| **FS-1xxx** | FS-1018MFP, FS-1020MFP, FS-1025MFP, FS-1030, FS-1035MFP, FS-1040, FS-1060DN, FS-1118MFP, FS-1120D/MFP, FS-1125, FS-1130MFP, FS-1135MFP |
| **FS-2xxx** | FS-2100D/DN, FS-2140DN, FS-2310DN, FS-2340DN |
| **FS-4xxx** | FS-4100DN, FS-4200DN, FS-4300DN |
| **ECOSYS M** | M2030dn, M2035dn, M2040dn, M2135dn, M2530dn, M2535dn, M2540dn, M2635dw, M2640idw, M2735dn, M2835dw, M3550idn, M3560idn |
| **ECOSYS P** | P2040dn, P2235dn, P2335dn, P3045dn, P3055dn |

⚠️ **Примечание:** после извлечения и повторной установки картриджа может потребоваться повторный сброс. На некоторых моделях (FS-1030, FS-1120D) вместо [Отмена] используется кнопка [Стоп/Сброс].

## Способ 2 — Механический сброс (TK-1248 / MA2001 / PA2001)

На моделях **Kyocera ECOSYS MA2001, MA2000, PA2001, PA2000** (картридж TK-1248 / TK-1240 / TK-1243) реализован **механический сброс** — флажок на картридже:

1. После заправки тонера **повернуть флажок** (белый рычажок) на боковой стороне картриджа.
2. Установить картридж в принтер.
3. Если ошибка осталась — извлечь, повернуть флажок обратно и снова установить.

Видео: [Заправка и сброс TK-1248 TK-1240 TK-1243 Kyocera MA2001 PA2001 PA2000](https://www.youtube.com/watch?v=sC5TdfnyNOA)

## Способ 3 — Сервисное меню (цифровая клавиатура)

Для моделей **с цифровой клавиатурой** (TASKalfa, старшие KM, старые FS):

### Вход в сервисный режим
1. Набрать на цифровой клавиатуре: **`10871087`**
2. На дисплее появится `U000` или вход в сервисное меню

### Основные сервисные программы

| Код | Назначение |
|---|---|
| **U001** | Выход из сервисного меню |
| **U251** | Сброс счётчика обслуживания (Maintenance Kit) — выбрать `CLEAR` |
| **U163** | Сброс ошибки печки (fixing unit) |
| **U021** | Инициализация памяти (Init Memory = сброс всех настроек) |
| **U106** | Сброс счётчика тонера (на некоторых моделях) |
| **U144** | Сброс ошибки лазера |

### Пример сброса U251
1. Войти: `10871087` → `U000`
2. Стрелками [↑][↓] выбрать `U251`
3. Нажать [Start] или [OK]
4. Выбрать `CLEAR` → Execute
5. Выйти: `U001` → Execute

## Способ 4 — Замена чипа

Для моделей, где кнопочный сброс не работает, **требуется замена чипа**:

- **TK-18** (FS-1018/1020/1118, KM-1815/1820) — блокирующий чип, замена обязательно
- **TK-100, TK-310, TK-3100, TK-3110** (офисные аппараты) — блокирующий чип
- **TK-320, TK-330, TK-340, TK-350, TK-360** — блокирующий чип
- **TK-4105, TK-435, TK-475** (TASKalfa) — блокирующий чип
- **TK-1248** — можно **механический сброс** (см. Способ 2), но также есть сменные чипы

- OZON, Wildberries — по запросу «чип Kyocera [модель]»

## Чип фотобарабана (Drum)
У некоторых моделей Kyocera (например, TASKalfa) есть отдельные **чипы на фотобарабан/девелопер**. Сброс — через U251 или замену.
