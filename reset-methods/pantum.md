# Pantum — прошивка и сброс счётчиков

## Общая информация

У всех картриджей Pantum **блокирующие чипы** — без замены чипа или прошивки принтер перестанет печатать после выработки ресурса. Два пути решения:

1. **Замена чипа** при каждой заправке (ресурс чипа = ресурсу картриджа).
2. **Бесчиповая прошивка** принтера — делается один раз, после неё чипы менять не нужно.

## Бесчиповая прошивка

| Ресурс | Описание |
|---|---|
| NoChip (nochip.ru) | Программа-прошивальщик, версии 5.x. Требует подключения принтера по USB. |
| fix-bay.com | Онлайн-генератор прошивок для Pantum, HP, Xerox, Samsung. |
| antichip.ru | Прошивки для HP, Samsung, Pantum, Xerox. |

Процесс (по antichip.ru):
- Прошивку разместить **в корень диска** (не на рабочий стол), путь без кириллических символов.
- Запустить от администратора, следовать инструкции.

⚠️ После прошивки принтер может перестать обновляться штатным ПО — гарантия производителя аннулируется.

## Сброс/обнуление чипа картриджа (без замены)

На некоторых моделях Pantum счётчик чипа можно сбросить кнопками (nodevice.com):

1. Выключить принтер, открыть крышку, вынуть картридж.
2. Включить принтер (без картриджа).
3. Зажать кнопку **OK** в меню на 5–10 секунд — чип сбросится.
4. Выключить принтер, вставить картридж, закрыть крышку.

⚠️ Работает не на всех моделях — на большинстве цветных (CP1100/CM1100) сброс кнопками недоступен, нужен чип или прошивка.

## Серия CLT-1100 (CP1100 / CM1100)

- Чипы блокирующие, замена обязательна: K 1000, C/M/Y 700, HK 2000, HC/M/Y 1500, XK 3000, XC/M/Y 2300 стр.
- Есть бесчиповая прошивка (~1500 р. в сервисах, CopyGroup) — после неё картриджи заправляются без ограничений.
- Продаются наборы чипов CMYK на OZON / Bulat / ChipCart / Grafit.
- Фотобарабан встроен в картридж, отдельного драм-чипа нет.
