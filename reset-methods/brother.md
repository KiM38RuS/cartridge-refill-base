# Сброс счётчиков Brother

## Общие принципы

Brother использует программный счётчик страниц для тонер-картриджа (TN-xxx) и для фотобарабана (DR-xxx). При достижении лимита принтер блокирует печать с сообщением «Замените тонер» или «Замените фотобарабан». **Чипы менять не нужно** — счётчик сбрасывается через меню или комбинации кнопок.

**Важно:** после заправки тонера обязательно сбросить счётчик, иначе принтер не будет печатать.

---

## Печать тестовой страницы

**Способ 1 — кнопка Go (все модели):**
1. Принтер включён, в режиме Ready
2. Нажать и удерживать кнопку **Go** ~3-4 секунды
3. Отпустить — принтер распечатает тестовую страницу / страницу состояния

**Способ 2 — через меню (модели с дисплеем):**
1. `Menu → Print Reports → Test Print`
2. Или: `Menu → Machine Info → Print Test`

**Способ 3 — для HL-1110/1210/DCP-1510 без дисплея:**
1. При выключенном принтере зажать и удерживать кнопку **Go**
2. Включить принтер, продолжая держать Go
3. Когда все индикаторы загорятся — отпустить

## Сброс счётчика тонера (Toner Reset)

### TN-1075, TN-1095 (HL-1110/1112/1210/1212, DCP-1510/1512/1602/1610, MFC-1810/1815/1912)

**Метод A (Go):**
1. Выключить принтер
2. Открыть переднюю крышку
3. Зажать кнопку **Go**, включить принтер
4. Дождаться, когда все индикаторы загорятся → отпустить Go
5. Закрыть крышку
6. Нажать **Go** дважды → подождать
7. Нажать **Go** 5 раз → дождаться сброса тонера
8. Закрыть/открыть крышку для завершения

**Метод B (для стартовых картриджей — без возможности сброса через меню):**
1. Извлечь тонер-картридж из аппарата, оставив только драм-юнит (DR-1075)
2. Найти датчик внутри аппарата (пластиковый флажок справа)
3. Нажать на флажок тонким предметом (отвёртка, спица) 3-5 раз
4. Установить картридж обратно — сброс выполнен

---

### TN-2075, TN-2135, TN-2175 (HL-2030/2040/2070, DCP-7010/7020/7030/7040, MFC-7225/7320/7420/7820)

**Сброс тонера:**
1. Включить принтер, дождаться Ready
2. Нажать **Go** — дождаться Ready
3. Нажать **Go** дважды → подождать
4. Нажать **Go** 5 раз — сброс тонера

**Сброс барабана (Drum):**
1. Включить принтер
2. Нажать **Menu/Set** → прокрутка **+** до **Machine Info**
3. Войти → прокрутка до **Reset Drum Count**
4. Нажать **Start** → подтвердить
5. Далее **Reset Life Count** → **Start**
6. Ввести код **96**, затем **98**, затем **99** (поочерёдно)
7. Выключить/включить принтер

**Альтернативный метод сброса барабана:**
1. Открыть крышку
2. Зажать **Go** на ~4 сек до мигания
3. Закрыть крышку — сброс выполнен

### TN-2085, TN-2090 (HL-2035, HL-2132, DCP-7057)

**Сброс тонера (HL-2035, 2132):**

2. Нажать **Go** — дождаться Ready
3. Нажать **Go** дважды → подождать
4. Нажать **Go** 5 раз — сброс тонера

**Сброс барабана:**
1. Открыть крышку
2. Зажать **Go** на 4 сек до мигания
3. Закрыть крышку

---

### TN-2235, TN-2275 (HL-2240/2240D/2250DN, DCP-7060/7065/7070)

**Сброс тонера и барабана:**
1. Включить принтер, дождаться Ready
2. Нажать **Go** — дождаться Ready
3. Нажать **Go** дважды → подождать
4. Нажать **Go** 5 раз — сброс выполнен
5. Выключить/включить

---

### TN-2335, TN-2375 (HL-L2300DR/2340DWR/2360DNR, DCP-L2500DR/2520DWR/2540DNR/2560DWR, MFC-L2700DWR/2720DWR/2740DWR)

**Сброс тонера:**
1. Включить принтер
2. Открыть переднюю крышку (оставить открытой)
3. Выключить принтер
4. Зажать кнопку **Go** и включить принтер
5. Дождаться, когда все индикаторы загорятся → отпустить Go
6. Закрыть крышку
7. Нажать **Go** 2 раза → подождать
8. Нажать **Go** 5 раз — сброс выполнен

**Альтернативный метод (через кнопки панели):**
1. Выключить принтер
2. Зажать **Clear/Back** + **Stop**
3. Включить принтер, удерживая кнопки
4. Дождаться инициализации
5. Нажать **+** на панели
6. Закрыть крышку — сброс выполнен

**Сброс барабана (DR-2335):**
1. Включить принтер, дождаться Ready
2. Нажать **Menu** → **Machine Info** → **Reset Drum Count**
3. Нажать **OK** → подтвердить
4. Выключить/включить

---

### TN-3030, TN-3060, TN-3130, TN-3170 (серия HL-5xxx)

**Сброс тонера:**
1. Включить принтер, дождаться Ready
2. Нажать **Go** — дождаться Ready
3. Нажать **Go** дважды → подождать
4. Нажать **Go** 5 раз — сброс тонера

**Сброс барабана:**

---

### TN-3330, TN-3380 (HL-5440/5450/5470/6180, MFC-8520)

**Сброс тонера:**
1. Нажать **Menu** → **Machine Info**
2. Выбрать **Reset Toner Count** → **OK**
3. Подтвердить

---

### TN-3430, TN-3480, TN-3512, TN-3520 (серия L5000/L6000/L8000)

**Сброс тонера (через меню):**
1. Нажать **Menu** → **Machine Info** → **Reset Toner Count**
2. Нажать **OK** → **Yes**

**Сброс барабана (DR-3405):**
1. Нажать **Menu** → **Machine Info** → **Reset Drum Count**
2. Нажать **OK** → **Yes**

---

1. Выключить принтер

## Дополнительно: прошивка принтера

Для некоторых моделей Brother (особенно современных) существует возможность прошить принтер для отключения счётчика тонера. Это позволяет не сбрасывать счётчик при каждой заправке. Прошивка выполняется через USB, обычно требуется скачать патч с profile.brother или специализированных сайтов.
