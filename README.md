# База знаний по заправке картриджей

Структурированная база данных, оптимизированная для работы ИИ-агентов в средах типа [Hermes Agent](https://github.com/AirbyteAI/hermes](https://github.com/nousresearch/hermes-agent)) или [Qwen Coder](https://coder.qwen.ai). Содержит спецификации картриджей, принтеров, чипов и расходных материалов для сервисных центров.

## 📂 Структура
- **`cartridges/`** — спецификации картриджей (HP, Xerox, Kyocera и др.): совместимость, ресурс, вес тонера.
- **`printers/`** — списки совместимых моделей принтеров.
- **`chips/`** — данные о чипах: артикулы, лимиты страниц, особенности сброса.
- **`materials/`** — характеристики тонеров и **[grammovki.md](materials/grammovki.md)** (вес стандартной порции).

## ⚡ Ключевые особенности
- **Система порций**: Вес тонера в базе указан как диапазон с множителем `(xN)`.
  - Пример: `625-700 (x6)` означает **6 готовых баночек** по 100 г (стандартная порция KYO).
  - *Не пересчитывайте вес вручную, используйте количество баночек.*
- **Источники**: Данные верифицированы на практике и дополнены техническими бюллетенями.
