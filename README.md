# База знаний по заправке картриджей

Структурированная база данных, оптимизированная для работы ИИ-агентов в средах типа [Hermes Agent](https://github.com/AirbyteAI/hermes](https://github.com/nousresearch/hermes-agent)) или [Qwen Coder](https://coder.qwen.ai). Содержит спецификации картриджей, принтеров, чипов и расходных материалов для сервисных центров.

## 📂 Структура
- **[`index.md`](index.md)** — полное оглавление базы знаний со ссылками на все документы.
- **[`cartridges/`](cartridges/)** — спецификации картриджей (HP, Xerox, Kyocera и др.): совместимость, ресурс, вес тонера.
- **[`printers/`](printers/)** — списки совместимых моделей принтеров.
- **[`chips/`](chips/)** — данные о чипах: артикулы, лимиты страниц, особенности сброса.
- **[`materials/`](materials/)** — характеристики тонеров и **[grammovki.md](materials/grammovki.md)** (вес стандартной порции).
- **[`tools/`](tools/README.md)** — инструменты для сбора цен с OZON (Python-скрипты, документация).
- **[`toner-types/`](toner-types/)** — сравнение типов тонеров (HP, Canon, Bulat), таблицы совместимости.
- **[`reset-methods/`](reset-methods/)** — методы сброса чипов для Brother, Kyocera, Pantum и других брендов.
- **[`raw/`](raw/index.md)** — сырые источники данных (PDF-документы, спецификации производителей).

## ⚡ Ключевые особенности
- **Всё в одном месте:** Единая структура объединяет совместимость картриджей, типы тонера, методы сброса ошибок и текущие цены.
- **Легко пополнять:** Чёткое разделение на «сырые» исходники (raw/) и готовые данные упрощает добавление новой информации и работу ИИ-агентов.
- **Актуальность:** Встроенные скрипты (tools/) помогают быстро обновлять цены и проверять наличие товаров.
- **Понятная навигация:** Главный файл index.md позволяет мгновенно находить нужный документ без долгого поиска по папкам.
