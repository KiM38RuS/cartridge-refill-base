# Инструменты: сбор цен OZON (картриджи/тонеры)

Скрипты для поиска товаров OZON и снятия цен. Проверены 2026-08-11 на примере Pantum CLT-1100.

## Когда что использовать

| Задача | Инструмент | Работает? |
|---|---|---|
| Найти товары по запросу (ссылки OZON) | `yandex_search.py`, `ozon_harvest.py` | ✅ Да |
| Получить HTML страницы товара напрямую | `ozon_fetch.py` | ❌ Нет (403/капча) |
| Диагностика блокировки | `ozon_probe.py` | ⚠️ Для анализа, не для сбора |
| Снять цену с карточки товара | **Реальный браузер** (см. ниже) | ✅ Единственный надёжный путь |

## Скрипты

### yandex_search.py — поиск по одному запросу
```bash
python tools/yandex_search.py "ozon чип clt-1100XK"
```
Возвращает ссылки `ozon.ru/product/...` и цены из сниппетов Яндекса.
- Работает через `curl_cffi` (impersonate="chrome"), Яндекс-сниппеты не блокируются.
- **Не заводится в `execute_code`** — там другой Python без curl_cffi. Запускать через terminal: `python tools/yandex_search.py "запрос"`.

### ozon_harvest.py — массовый сбор ссылок по списку запросов
- Список запросов — в массиве `queries` в начале файла.
- Результат: уникальные ссылки с числом повторов, сохраняет `_ozon_links.json`.
- ⚠️ Фильтровать мусор: запросы C/M/Y часто возвращают товары других брендов (Samsung, Kyocera и т.п.) — по названию картриджа отбрасывать.

### ozon_fetch.py — прямой запрос страницы OZON
- **403 + JS-капча «собери пазл»** — OZON блокирует скрипты, даже с impersonate="chrome".
- Сохраняет полученный HTML в `_ozon_<hash>.html` — полезно как образец тела капчи (`ozon_403_sample.html`).

### ozon_probe.py — диагностика блокировки
- Показывает текст 403-ответа и пробует composer API — для понимания механизма блокировки, не для сбора.

## Снятие цен через реальный браузер (единственный рабочий путь)

1. **Остановить Hiddify VPN**: `"/c/Program Files/Hiddify/HiddifyCli.exe" tunnel stop` (VPN-IP OZON блокирует капчей; команды `stop` не существует, только `tunnel stop`).
2. **Открыть страницу товара в отдельном окне Edge** (обходит перехват адресной строки и переполнение вкладок):
   ```bash
   "/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --new-window "https://www.ozon.ru/product/1442545782/"
   ```
   ⚠️ В профиле «Личный» адресная строка Edge перехватывается oauth.yandex.ru — ввод URL вручную уводит на Яндекс. Только `--new-window <url>` из терминала.
3. **Снять цену через computer_use** (AX-дерево): кнопка вида `756 ₽ С банками` = цена с доп. скидкой. Рядом: `840 ₽` (обычная/со скидкой), `2 000 ₽ С другими банками` (базовая).
4. Варианты товара (цвета) переключаются кликом по чипу цвета в блоке «Цвет тонера/чернил» — страница обновляется, артикул меняется (например 1028469382 → чёрный 1028469414).

## Правила цены

- OZON показывает **три цены**: обычная → со скидкой → с доп. скидкой при оплате банками.
- В базу фиксировать **всегда цену с доп. скидкой** (самая низкая) — кнопка «... ₽ С банками».
- Записывать и остальные две для контекста: обычная (цена после скидки) и базовая («С другими банками»).

## Координаты computer_use (Edge, экран 1920×1080)

- Скриншот 1456px ↔ реальные 1920px — множитель ~1.318.
- Клики в AX-дереве даются в image-координатах; `list_windows` даёт реальные `window_id` для нескольких окон Edge (важно: `capture` с `window_id` работает, без него — переднее окно).

## Зависимости

- `curl_cffi` — только для terminal-Python (в execute_code другой Python, ставить `pip install curl_cffi` в terminal).
- Для browser-пути: компьютер с Edge, computer_use.
