# Чипы для картриджей

## Общая информация

**Чип** — микросхема на картридже, хранящая информацию о модели, производителе, ресурсе (количество страниц), количестве установок, оригинальности. Обменивается данными с принтером.

### Типы чипов

| Тип | Описание |
|---|---|
| **Блокирующие** | По исчерпании ресурса (количество страниц) **блокируют печать**. Без замены чипа принтер не работает. |
| **Информационные** | Не блокируют печать, только передают информацию (уровень тонера, модель). |
| **С автосбросом (Auto-reset)** | Сбрасывают счётчик автоматически после каждого цикла «извлечение → установка картриджа». Могут работать нестабильно. |
| **Перезаписываемые** | Можно перепрограммировать специальным программатором. |

### Принцип работы

- Чип считает **количество страниц** (при 5% заполнении), а не реальный расход тонера
- Если печатать с большим заполнением (>5%), тонер кончится раньше, чем чип сообщит об окончании
- Если печатать с малым заполнением, чип может заблокировать печать, когда тонер ещё есть

### Что делать при заправке

- **Если чип блокирующий** — менять обязательно, иначе принтер не будет печатать
- **Если чип информационный** — менять не обязательно
- **Альтернатива** — перепрошивка принтера (замена заводской прошивки на версию без блокировки чипов)

## Pantum

### Важно

- **Все картриджи Pantum** используют **блокирующие чипы**
- При заправке чип **нужно менять обязательно**
- После замены чипа может потребоваться **обновить драйверы** с официального сайта Pantum — иначе принтер может «убить» (заблокировать) новый чип
- Есть **совместимые чипы с автосбросом** («безлимитные») — работают нестабильно

У картриджей Pantum TL-серии есть отдельный **чип на фотобарабан** (DL-420, DL-410 и т.д.):
- DL-420: ресурс 9000–30000 стр.
- При ошибке «ФБ заканчивается» / «Drum End» — требуется замена чипа фотобарабана

## Canon 069 / 069H

- **Обязателен** для заправки (без чипа принтер не делает калибровку цветов)
- Без чипа возможна печать, но калибровка не работает, цвета плывут
- Цена: ~1 900–3 200 руб (данные 2024 г.)
- Дорогие по сравнению с другими моделями
- Неоригинальные чипы могут не работать с калибровкой
- Решение: полная инициализация принтера через меню сбрасывает настройки калибровки

## Brother

### Особенности

Brother использует **программные счётчики**, а не блокирующие чипы. Физически чип на картридже есть, но его не нужно менять — счётчик сбрасывается через меню принтера или комбинации кнопок.

- **TN-xxx** — чип есть, но **не блокирующий**. Сброс через Go-кнопку или меню.
- **Стартовые картриджи** (в комплекте с принтером) — могут иметь пониженный ресурс и сбрасываются нажатием на датчик внутри аппарата.
- **DR-xxx (фотобарабан)** — отдельный счётчик, сбрасывается через `Menu → Machine Info → Reset Drum Count`.
- Полные инструкции по сбросу: [Сброс счётчиков Brother](../reset-methods/brother.md).

### Особенности

- У картриджей HP W1106A (106A) чип **блокирующий**, но на некоторых принтерах можно отключить через меню.

- При заказе чипы часто называют «**107**» — по принтеру **HP Laser 107a/107r/107w**, который первым указан в совместимости.
