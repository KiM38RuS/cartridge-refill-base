# Граммовки — формулы расчёта веса тонера

## Формулы из файла «Граммовки»

```
1200 = 1000 / 8  =  125 г   — стандартная пачка 1 кг на 8 картриджей
1005 = 1000 / 16 =  62,5 г  — пачка 1 кг на 16 картриджей
SAM  =  700 / 14 =  50 г    — Samsung
KYO  =  900 / 9  = 100 г    — Kyocera
FC   =  900 / 6  = 150 г    — Fuji Xerox / Canon
BRO  =  500 / 6  =  83,3 г  — Brother
PAN  =  500 / 8  =  62,5 г  — Panasonic
104  =  (PAN)    =  62,5 г  — тип 104
```

## Пояснение
Расшифровка шифров типов тонера (встречаются в xlsx-базе):
- **1005** — тонер для HP/Canon, ~62,5 г на картридж
- **1010** — тонер для HP (LJ 1010 и аналоги), ~120-125 г
- **1025** — тонер для HP Color/Canon цветной
- **104** — тонер для HP LJ Pro M104, ~70 г
- **1200** — универсальный тонер для HP/Canon, ~125 г
- **1215** / **2025** — цветные тонеры

На практике граммовка может варьироваться ±10 г в зависимости от производителя тонера.
