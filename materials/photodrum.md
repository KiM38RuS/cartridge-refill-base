# Фотобарабаны (фоторецепторы)

## Для Canon 069/069H
- Фотобарабан снимается отдельно (как у CF218A)
- Отработки нет (система без отработанного тонера)
- Вал нужно менять при заправке

## Для Canon 728
- Есть видео по перебивке шестерни фотобарабана

## Для Brother
- DR-2275 — барабан для DCP 7057
- DR-xxxx — различные модели
