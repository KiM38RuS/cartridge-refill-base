# Тестовые страницы и калибровка

## Тестовые листы
- `Тест.docx` / `Тест.pdf` / `Тест.png` — стандартные тестовые страницы
- `Тест 2.docx` — дополнительный тест
- `Тест 3.docx` — ещё один тестовый набор
- `Тест WPS.docx` — тест для WPS
- `Тест цветной.docx` — цветная тестовая страница
- `Тест цветной на весь лист.jpg` — цветной тест на А4
- `481_test-cmyk-2.jpg` — CMYK-тест
- `test_serie_for_web.pdf` — серия тестов для веб

## Калибровка
- `Калибровочный-лист.pdf` — калибровочный лист
- `Проверка-принтера-на-печать-градиентов-серого-цвета.pdf` — проверка градиентов серого

## Использование
После заправки картриджа и калибровки цветов рекомендуется печатать:
1. Калибровочный лист для проверки цветопередачи
2. Тест градиентов серого для проверки равномерности
3. Цветной тест для финальной проверки
