# Тонер-менеджер Desktop: DESIGN.md

## Общее описание
Приложение-десктопный клиент для управления базой знаний "Заправка" (тонер-картриджи, принтеры, запчасти, методы сброса). Цель — удобный поиск, просмотр и добавление информации.

## Технологический стек
- Язык программирования: Python 3.11
- GUI: PySide6
- СУБД для индексации: SQLite (локальный файл)
- Интерфейс: светлая/тёмная тема, pixel-perfect under Windows 11

## Архитектура проекта
```
tonermanager/
├── main.py             # Точка входа, запуск QApplication
├── ui_main.py          # Главное окно
├── ui_search.py        # Виджет поиска
├── ui_editor.py        # Виджет редактирования / добавления
├── db.py               # Работа с SQLite
├── wiki_parser.py      # Парсер markdown-файлов базы
├── config.py           # Настройки (тема, пути)
├── requirements.txt
└── README.md
```

## Функциональные требования

### 1. Поиск по базе знаний
- Полнотекстовый поиск по содержимому markdown-файлов
- Фильтрация по категориям:
  * Картриджи ([cartridges/*](file://cartridges))
  * Принтеры ([printers/*](file://printers))
  * Типы тонера ([toner-types/*](file://toner-types))
  * Чипы ([chips/*](file://chips))
  * Методы сброса ([reset-methods/*](file://reset-methods))
  * Расходники ([materials/*](file://materials))
- Отображение результатов в виде дерева/списка
- Переход к источнику файла при выборе результата

### 2. Просмотр и редактирование
- Просмотр содержимого выбранной статьи в Markdown-формате
- Поддержка базового редактирования (bold, заголовки, списки, ссылки)
- Автоматическое сохранение изменений в файл
- Возможность создания новых статей
- Шаблоны для новых статей по типу контента

### 3. Индексация и синхронизация
- Автоматическая индексация всех markdown-файлов в базе
- Поддержка переиндексации по запросу
- Синхронизация изменений между файловой системой и поисковым индексом

### 4. Управление контентом
- Добавление новых картриджей с автозаполнением по модели принтера
- Добавление информации о принтерах и их совместимости
- Управление типами тонера и их характеристиками
- Ведение журнала изменений (log.md)

## Требования к пользовательскому интерфейсу

### Главное окно
- Меню: Файл / Поиск / Инструменты / Настройки
- Боковая панель навигации с деревом категорий
- Центральная область — редактор/просмотрщик контента
- Нижняя панель статуса с информацией о файле и состоянии
- **Режим вкладок**: можно открывать несколько статей во вкладках (как в браузере)
- **Режим отдельных окон**: можно открывать статьи в отдельных окнах (для параллельной работы)
- **Переключение между режимами** в настройках или через контекстное меню

### Панель поиска
- Поле ввода запроса
- Фильтры по категориям
- Кнопки "Найти далее" / "Назад"
- Отображение количества результатов

### Редактор
- **Markdown-редактор с тулбаром** (QPlainTextEdit + QToolbar)
- Мини-редактор с поддержкой:
  * # Заголовки (H1-H3)
  * **Жирный** текст
  * *Курсив*
  * [Ссылки](url)
  * Маркированные и нумерованные списки
  * Кнопки форматирования в тулбаре
- Автосохранение при потере фокуса
- Поддержка клавиатурных команд (Ctrl+S, Ctrl+F и др.)
- Live preview (можно выключить в настройках)

## Логика работы

### Инициализация
1. Проверка наличия папки базы (`/d/YandexDisk/Заправка/БАЗА`)
2. Если БД индекса не существует — создание и первичная индексация
3. Загрузка настроек пользователя (тема, последние открытые файлы)

### Поиск
1. Получение текстового запроса пользователя
2. Опциональная фильтрация по категории
3. Поиск в SQLite FTS5 (полнотекстовый поиск)
4. Отображение результатов с подсветкой совпадений
5. Можно выбрать результат → открытие в редакторе

### Добавление новой статьи
1. Выбор категории (картриджы/принтеры/и т.д.)
2. Ввод заголовка и содержимого
3. Автоматическое создание файла с шаблоном
4. Добавление ссылки в index.md
5. Запись в log.md

## Требования к хранению данных
- Все изменения сохраняются в виде markdown-файлов в соответствии со структурой БАЗА/
- Индекс поиска — отдельный SQLite-файл в корне проекта
- Журнал изменений (log.md) обновляется автоматически

## Безопасность
- Приложение работает только с локальными файлами
- Нет подключения к интернету (опционально можно добавить проверку обновлений)
- Резервное копирование важных файлов перед изменением
