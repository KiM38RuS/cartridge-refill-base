# База картриджей: Samsung

## Чипы

Большинство картриджей Samsung используют **блокирующие чипы**. При заправке требуется замена чипа, иначе принтер блокирует печать («Закончился картридж»). 

- **MLT-DxxxS/L/E** — чипы, ресурс совпадает с ресурсом картриджа
- Для некоторых моделей (MLT-D101S, MLT-D111S) есть **прошивка принтера**, отключающая проверку чипа
- **Классические ML-xxxxDx** (ML-1610D2, ML-2010D3 и др.) — часто **чипов нет**, заправляются без замены
- **CLT-xxxS** (цветные) — блокирующие чипы, менять обязательно

Подробнее: [Чипы для картриджей → Samsung](../materials/chips.md#samsung).
