## Чипы

У Ricoh SP-серии (SP 100/150/200/230/311/340/C220/C250/C310) и офисных MP/IM — **блокирующие чипы**. При заправке требуется замена чипа, иначе принтер блокирует печать. Для SP 230 есть возможность механического сброса (флажок). Подробнее: [Чипы для картриджей → Ricoh](../materials/chips.md#ricoh).
