# Canon 052 (2199C002)

## Общие сведения
- **Производитель:** Canon
- **Модель:** 052 / 2199C002
- **Цвет:** Black (чёрный)
- **Ресурс (ISO 5%):** 3 100 страниц
- **Принтеры:** Canon i-SENSYS LBP-212, LBP-214, LBP-215; MF-426, MF-428, MF-429
- **Тип тонера:** 1005

## Вес тонера
- **Заводская заправка:** ~70 г (указано как 70×2, возможно два бункера или две порции)

### Версия 052H (2200C002) — повышенной ёмкости
- **Ресурс:** 9 200 страниц
- **Вес:** ~350 г

## Совместимые тонеры
1. **HiBlack HP LJ P1005** — основной рекомендуемый вариант
2. Nandan HG391
3. IMEX CMG-3
4. SC P1505
5. ХайБлэк M604 Тип 5.0

## Заправка
- Тонер тип 1005 — совместим с тонерами для HP P1005/P1505
- Чип не блокирует работу (уточнить)
