# AGENTS.md — Схема базы знаний «Заправка»

Этот файл — инструкция для LLM-агента по ведению базы знаний о заправке тонер-картриджей.

## Структура каталогов

```
БАЗА/
├── AGENTS.md            ← этот файл (схема)
├── index.md             ← оглавление всех страниц
├── log.md               ← хронологический лог изменений
├── cartridges/          ← картриджи по моделям
│   ├── canon-069HY.md
│   └── ...
├── printers/            ← принтеры и МФУ
│   └── ...
├── toner-types/         ← марки/типы тонера (Bulat, TMC, Grafit...)
│   └── ...
├── chips/               ← чипы для картриджей
│   └── ...
├── reset-methods/       ← методы сброса счётчиков
│   └── ...
├── materials/           ← расходники (фотобарабан, ракель, магнитный вал...)
│   └── ...
├── tools/               ← скрипты и методики (сбор цен OZON и т.п.)
│   └── README.md
└── raw/                 ← сырые источники (неизменяемые)
    └── ...
```

## Правила ведения wiki

1. **При ingest** нового источника: прочитать, выделить ключевые факты, обновить/создать страницы в wiki, обновить index.md, записать в log.md.
2. **Формат страниц**: Markdown. Каждая страница начинается с `# Название`. В конце — `---` и строка `*Источник: ...*`.
3. **Ссылки** на другие страницы: `[текст](относительный/путь.md)`.
4. **При обновлении**: не удаляй старую информацию, а дополняй — знания накапливаются. Если данные противоречивы — отметь `⚠️ Противоречие:` и объясни.
5. **index.md** обновляется при каждом добавлении/изменении страницы.
6. **log.md** — append-only запись вида: `## [ГГГГ-ММ-ДД] действие | Тема`
