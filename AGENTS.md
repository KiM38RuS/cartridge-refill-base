# AGENTS.md — Схема базы знаний «Заправка»

Этот файл — инструкция для LLM-агента по ведению базы знаний о заправке тонер-картриджей.

## Структура каталогов

```
БАЗА/
├── AGENTS.md            ← этот файл (схема)
├── index.md             ← оглавление всех страниц
├── log.md               ← хронологический лог изменений
├── cartridges/          ← картриджи по моделям
│   ├── canon-069HY.md
│   └── ...
├── printers/            ← принтеры и МФУ
│   └── ...
├── toner-types/         ← марки/типы тонера (Bulat, TMC, Grafit...)
│   └── ...
├── chips/               ← чипы для картриджей
│   └── ...
├── reset-methods/       ← методы сброса счётчиков
│   └── ...
├── materials/           ← расходники (фотобарабан, ракель, магнитный вал...)
│   └── ...
├── tools/               ← скрипты и методики (сбор цен OZON и т.п.)
│   └── README.md
└── raw/                 ← сырые источники (неизменяемые)
    └── ...
```

## Правила ведения wiki

1. **При ingest** нового источника: прочитать, выделить ключевые факты, обновить/создать страницы в wiki, обновить index.md, записать в log.md.
2. **Формат страниц**: Markdown. Каждая страница начинается с `# Название`. В конце — `---` и строка `*Источник: ...*`.
3. **Ссылки** на другие страницы: `[текст](относительный/путь.md)`.
4. **При обновлении**: не удаляй старую информацию, а дополняй — знания накапливаются. Если данные противоречивы — отметь `⚠️ Противоречие:` и объясни.
5. **index.md** обновляется при каждом добавлении/изменении страницы.
6. **log.md** — append-only запись вида: `## [ГГГГ-ММ-ДД] действие | Тема`
7. **Интерпретация веса тонера (пометка xN)**:
   - Если в базе вес указан как `XXXX-YYYY (xN)` (например, `625-700 (x6)`), это означает, что для заправки требуется **N порций** предварительно расфасованного тонера.
   - Вес одной порции определяется по файлу [`materials/grammovki.md`](materials/grammovki.md) в зависимости от типа принтера (KYO, SAM, FC, BRO и т.д.).
   - **Пример**: Для Kyocera (KYO) базовая порция = 100 г. Запись `625-700 (x6)` означает 6 баночек по 100 г (итого ~600 г, диапазон учитывает потери или особенности модели).
   - **Запрещено** вычислять вес одной порции делением общего диапазона на N (например, нельзя писать "104–117 г"). Всегда используй фиксированный вес порции из `grammovki.md`.
8. **Приоритет источников**:
   - При запросах о картриджах, принтерах, чипах и расходниках **в первую очередь** используй данные из файлов базы (`cartridges/`, `printers/`, `chips/`, `materials/`).
   - Только если информация в базе отсутствует, выполняй веб-поиск и обязательно добавляй найденные данные в соответствующие файлы базы.
   - Не используй общие знания (general knowledge) вместо данных из базы, если база содержит информацию по запросу.
